# TIT Bhopal Modern College Website

React + Vite frontend prototype for Technocrats Institute of Technology, Bhopal.

## Run
1. Install Node.js.
2. Open this folder in VS Code.
3. Run:
   npm install
   npm run dev
4. Open the localhost URL shown by Vite.

## Chatbot
The chatbot UI is already implemented in:
src/components/Chatbot.jsx
src/components/ChatMessage.jsx
src/components/ChatInput.jsx

Replace the placeholder `sendMessage()` function in `Chatbot.jsx` with your own API/backend or knowledge-base integration. Never put a private API key directly in the React frontend.

## Important
Several college figures, dates, contact details, testimonials, recruiter names and other institutional details are deliberately marked as illustrative/placeholders. Verify them against official TIT information before publishing.
